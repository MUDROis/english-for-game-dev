# Создание уроков — инструкция платформы «English for Game Dev»

Как добавить новый урок на платформу (статический сайт под GitHub Pages).
Один урок = один самостоятельный HTML-файл в `lessons/`, никаких сборщиков и бэкенда.

---

## 1. Где что лежит

```
english-course-site/
├── index.html              # карта курса: массив COURSE (12 модулей × 4 урока) + библиотека ресурсов
├── lessons/
│   ├── m01-01.html …       # готовые уроки (m<модуль 2 цифры>-<урок в модуле 2 цифры>.html)
│   └── _template.html      # скелет урока — копировать отсюда
├── assets/
│   ├── css/style.css       # вся стилизация (тёмная тема, классы секций/упражнений)
│   ├── js/engine.js        # движок: все интерактивные упражнения (EC.*)
│   ├── img/                # иллюстрации: l5-xxx.png, l6-xxx.png …
│   └── audio/              # дорожки: m02-01-warmup.mp3, m02-01-listening.mp3 …
├── .nojekyll               # обязательно: отключает Jekyll на GitHub Pages
└── README.md
```

Нумерация глобальная, но имена файлов — по модулю: уроки 5–8 (модуль 2) = `m02-01.html … m02-04.html`.

---

## 2. Структура урока (одинаковая для всех 48)

Секции идут строго по годовому плану, у каждой `id` и кнопка «Mark as done»:

| # | Секция | id | Время |
|---|--------|----|-------|
| 1 | Warm-up | `warmup` | 5–10 мин |
| 2 | Listening (аудио + 10 ключевых слов + 2 задания) | `listening` | 10–12 мин |
| 3 | Reading (текст + задания + внешняя ссылка) | `reading` | 8 мин |
| 4 | Grammar (правила + 4 упражнения + shadowing) | `grammar` | 10–15 мин |
| 5 | Grammar → Speaking (раунды с записью голоса) | `speaking` | 10–15 мин |
| 6 | Writing **или** Module Test (в 4-м уроке модуля) | `writing` / `test` | 5–15 мин |
| 7 | Homework (чек-лист) | `homework` | ≤30 мин |

Прогресс-бар в шапке считается по секциям, объявленным в `SECTIONS` (внизу файла).

## 3. Как создать новый урок — пошагово

1. **Скопируйте** ближайший готовый урок той же роли (обычный урок → `m01-02.html`;
   финальный урок модуля с тестом → `m01-04.html`) в новое имя, например `m02-01.html`.
2. **Замените** в шапке: `<title>`, crumb (`Module 2 · … · Lesson 5 / 48`), `h1`, цель урока
   (`.goal`) и чипы-якоря секций.
3. **Контент** — из годового плана (DOCX) и данных модуля: вопросы разминки, тема аудирования,
   грамматика, речевые задания, письмо, домашка. Сценарий урока не менять.
4. **История-сквозняк**: в аудио и текстах живут Dana, Priya (арт-директор), Tom (QA-лид)
   и студия Harbour Lights. Продолжайте её; вплетайте контекст ученицы: она PM/Team Lead
   и проходит курс тестировщика игр (QA course) — давайте ей задания «из её жизни».
5. **Ссылки**: только на конкретную страницу урока, не на оглавление
   (например `https://test-english.com/grammar-points/b1/past-simple-past-continuous-past-perfect`,
   а не `/grammar-points/b1`). Перед публикацией откройте ссылку и проверьте.
6. **Зарегистрируйте урок** в `index.html`: в массиве `COURSE` добавьте объекту урока
   `url:"lessons/m02-01.html"` и однострочное описание `d:"ключевые слова · грамматика · крючок-вопрос"`.
7. Обновите `<footer>` на index (какие модули готовы) и README.

## 4. Движок упражнений — шпаргалка (assets/js/engine.js)

Все функции принимают CSS-селектор контейнера и данные. Каждому упражнению — свой `exKey`
(в него пишется лучший результат в localStorage).

```js
EC.initLesson('m02-01', [ {id:'warmup', title:'Warm-up'}, … ]);   // прогресс-бар, 7 секций

EC.flipGrid('#sel', [ {front:'…', back:'…'}, … ]);                // карточки-переворотыши (клик)
EC.vocab('#sel',  [ {w:'a bug', d:'определение (рус.)', e:'English example'}, … ]); // чипы словаря
EC.mcq('#sel',  { title, exKey, items:[ {q, opts:[…], a:1, why:'…'} ] });   // выбор варианта
EC.tf('#sel',   { title, exKey, items:[ {s:'утверждение', a:true, why, hint} ] }); // true/false
EC.gap('#sel',  { title, exKey, items:[ {t:'… ___ …', a:['answer'], verbs:['подсказка']} ] }); // вставить слово
EC.order('#sel',{ title, exKey, items:[ {words:[…], answer:'…', ru:'русский источник'} ] }); // собрать предложение
EC.sort2('#sel',{ title, exKey, items:[ {w:'предложение', a:'ps'|'pc'} ] }); // сортировка в 2 колонки
EC.writer('#sel',{ task, placeholder, min:50, max:90 });          // письмо + счётчик слов
EC.recorder('#sel', {maxSec:90, hint:'…'});                       // запись голоса (в браузере)
EC.checklist('#sel', { items:[ {t:'пункт', m:'подсказка'} ] });   // чек-лист домашки
EC.enhanceAudio();                                                // кнопки скорости 1× / 1.25× / 1.5×
```

Правила контента упражнений:
- русский — **только** в переводах новой лексики (`d` в `EC.vocab`) и в русских
  предложениях-источниках (`ru` в `EC.order`); весь интерфейс и задания — на английском;
- в каждом `why`/`hint` объясняйте время/правило одним предложением;
- теги цветов: `<span class="tag ps">…</span>` (Simple, оранжевый), `tag pc` (Continuous, синий),
  `tag pf` (Perfect, красный);
- типичные ошибки русскоязычных — в блоке `🩹` с классами `no` / `yes`.

## 5. Аудио (TTS, голос xiaochen, темп 1.05)

5 дорожек на урок, имена фиксированы: `mXX-YY-warmup / -vocab / -listening / -shadowing-a / -shadowing-b.mp3`.

Генерация (скрипт-образец: `scripts/gen_audio_m01_xiaochen.sh`):

```bash
z-ai tts -i "TEXT" -o /tmp/x.wav -v xiaochen -s 1.05
# выравнивание громкости до -20 dBFS (как во всех готовых дорожках):
ffmpeg -i /tmp/x.wav -af "volume=<GAIN>dB" -codec:a libmp3lame -q:a 4 assets/audio/m02-01-warmup.mp3
```

- Текст дорожки ≤1024 символов; длиннее — генерируйте 2 части и склейте `ffmpeg concat`.
- Слушайте готовый файл до публикации: речь должна быть живой, без обрывов.
- При ошибке `429 Too many requests` — пауза 20–60 с и повтор (в скрипте есть ретраи).
- Медленных версий не делать: на страницах есть кнопки ускорения.

Аудио-контент: warm-up = вопросы разминки; vocab = 10 слов с английскими определениями;
listening = оригинальная история про студию с грамматикой урока; shadowing-a/b = по 6 коротких
предложений «Repeat after me. One. …» под грамматику урока.

## 6. Иллюстрации

```bash
z-ai image -p "Flat vector illustration, wide: …, warm orange accents on dark graphite
background, clean minimal style, no text, high quality" -o assets/img/l5-superhero.png -s 1344x768
```

- Стиль единый: flat vector, тёмно-графитовый фон, оранжевые акценты, **no text**.
- Широкие 1344×768 — под секции Listening/Speaking; квадратные 1024×1024 — под сравнение картинок.
- Всегда заполняйте `alt` по-английски.

---

## 7. Видео и внешние материалы

- YouTube: только `youtube-nocookie.com/embed/<ID>`, `loading="lazy"`, `allowfullscreen`,
  и рядом текстовая ссылка «watch on YouTube ↗» (на случай блокировок).
- ID видео проверяйте перед врезкой (страница должна открываться и называться так, как заявлено).
- BBC 6 Minute English / TED / The Guardian — ссылка + двухшаговое задание
  («first listen …, second listen …»).

## 8. Чек-лист перед публикацией урока

- [ ] Открыть `lessons/mXX-YY.html` локально: секции, прогресс-бар, все упражнения считаются, аудио играет.
- [ ] Тёмный текст не встречается на тёмном фоне; русский только в словаре/`ru`.
- [ ] Все внешние ссылки открывают конкретную страницу (не оглавление).
- [ ] В `index.html` у урока появились `url` и `d`; строка описания ≤ 1 строки.
- [ ] `README.md` и `<footer>` index.html отражают актуальный список готовых модулей.
- [ ] `git add -A && git commit && git push` — GitHub Pages обновится за 1–2 минуты.

Локальная проверка: `python3 -m http.server 8000` в папке сайта → `http://localhost:8000`.

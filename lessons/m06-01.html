If I Had More Funding…, What Would Change?

Module 6 opens the multiverse — the language of hypotheses, regrets and alternative histories. Lesson goal: talk about unreal presents and startup dreams in the second conditional (If + Past Simple, would + infinitive) — if we had a publisher, we would ship twice as fast. The past tense here is not about the past: it is distance from reality.

Grammar — The Second Conditional

10 mindreams + 4 exercises

SECOND CONDITIONAL — the dream

  • Form: If + Past Simple, would + infinitive — If we had a publisher, we would ship faster.
  • Meaning: unreal or unlikely right now — dreams, hypotheticals, pitches.
  • The past here is not past time: it is distance from reality. «был/бы» — но не про прошлое!
  • Classic form: if I were, if she were, if we were — If I were the CEO, lunch breaks would be sacred.
Quick test: if you can start the sentence with "in an ideal world…" — it is second conditional.

🧪 Where the dream applies

  • Startup decisions: If we charged per episode, players would complain.
  • Wishes about now: If I had twice the budget, I would hire two artists.
  • Advice: If I were you, I would build a small demo first.
  • Choices: I would rather build a puzzle game than a shooter.
could also works in the result half when ability is the point: If we had a bigger budget, we could hire two more artists.

⚙️ Mini-table — dream, plan or law?

SentenceWhy?
If the build fails, we roll back.True every time → zero (a law, Module 5).
If QA approves the build on Wednesday, we will ship on Friday.Real and possible, one concrete future → first (a plan, Module 5).
If we had a publisher, we would ship twice as fast.No publisher exists — an unreal present → second.
If I were the QA lead of a richer studio, I would buy forty test phones.A dream about right now → second (were, not was — classic form).
If we sold cosmetic cat hats, revenue would grow.A hypothetical product line → second, and a real merch idea.
🩹 Typical mistakes of Russian-speaking dreamers: If we would have a publisher… → If we had a publisher… (no would in the if-half) · If I was the CEO… → If I were the CEO… (were for dreams — the safe classic; you will hear was in songs) · If we had more money, we will ship faster → …we would ship faster (would, not will, in the dream half) · If I had a publisher, I would slept better → …I would sleep better (infinitive after would, not past).

Grammar → Speaking — the main section of the lesson

15 mingoal: dreams that sound natural
The 5-second rule: before every hypothesis ask silently: is this real, or is this a dream? If you catch yourself saying "if we will have a publisher" — stop, rebuild calmly: "if we had a publisher, we would…" Past simple + would — that is the whole machine.

🎙 Round 1 — Startup Multiverse 6 hypotheses

Six hypotheses about your company (real, study or dream one) — all with would. Model: if we charged per level, players would complain; if I were the only developer, I would focus on one platform. 90 seconds.

If we had a bigger budget, we … If we charged per level, players … If I were the only developer, I … If the studio gave us one extra hour, we …

🎙 Round 2 — Marvel Pitch one multiverse of yours

Invent your own "multiverse": what would the world look like if the Avengers were a game studio? Who would do QA? What would their crunch look like? 90 seconds, at least five would-sentences.

If the Avengers were a game studio, Thor would … If Hulk did QA, every bug would … If Tony Stark ran the pipeline, builds would …

🎙 Round 3 — Would You Rather (the plan's core drill)

Eight questions, two options each — answer every one with a full sentence in the second conditional or with would rather: I would rather build a puzzle game than a shooter. No one-word answers — the grammar lives in the full sentence.

Would you rather ship one big game or three small ones? Would you rather work with no deadlines or no weekends? If you could add one superpower to QA, what would it be? If a publisher offered you money but total control of the story — would you sign?

⚡ Speed Drill — a universe every 5 seconds

Open a card and instantly say the dream it hides — out loud, in the second conditional.

Homework

≤ 30 minutes in total
🧑‍🏫 Teacher notes

Goal: the student talks about unreal presents fluently — If + Past Simple, would + infinitive — and stops treating the past tense in the if-half as past time. «Было бы» = past simple + would, a distance marker, not a clock.

Suggested flow: Warm-up: budget ×2, parallel careers, fictional hires — push every answer to "if I had…, I would…" → Listening: the multiverse pitch; second pass copies two dreams word for word → Reading: the wiki board labels 6 hypotheses; the BBC Culture extension retells a franchise with would → Grammar: the mini-table's "dream, plan or law?" rows decide everything; the video consolidates → Speaking: Round 3 (would you rather) is the module's fluency drill — full sentences only → Writing: the multiverse memo is a light artefact; keep the funniest line for Lesson 24's debate.

Success criteria: Round 1 — 6 hypotheses, no would in the if-half; Round 2 — five would-sentences about the Avengers universe; Round 3 — 8 full-sentence answers, at least three with would rather or were.

Error pocket: would in the if-clause (if we would have) · will instead of would in the result half · was for dreams where were is classic (if I was the CEO) · past after would (would slept) · translating «если бы» with "if only" by default — "if only" is emotional and belongs to Lesson 23.

Threads: the multiverse board returns in Lesson 22 as the post-mortem wall (dreams about the present become regrets about the past); the cat-hat merchandise becomes a running joke and returns in Lesson 24's debate; would rather gets its full treatment in Lesson 23 next to wish.

Reading — The Press Release (internal wiki)

10 mintense spotting

Harbour Lights Wiki · Page 24: The Press Release

Category: press · Owner: Dana · Status: approved, published, celebrated

Grammar check: every sentence is a different passive tense. Label them as you read.

1. Lighthouse Point was announced last spring. (past simple)

2. Since then, three demos have been shown, and the demo was played by more than fifty thousand people. (present perfect + past with by)

3. The game is being localized into nine languages — Japanese and Korean will be added next month. (present continuous + future)

4. The soundtrack was recorded by a live orchestra, and the credits are watched to the very end. (past + present)

5. The day-one patch must be downloaded before the first launch. (modal passive)

6. The studio was founded eight years ago in a kitchen. (past, the classic)

Grammar — The Passive System (consolidation)

10 minall tenses + 4 exercises

🗺 The system — one table, one engine

Tense / formExample — the life of one build
Present SimpleThe build is tested nightly.
Past SimpleThe trailer was released last month.
Present ContinuousThe patch is being tested right now.
Present PerfectTwo bugs have been found since launch.
FutureThe game will be released on Friday.
Modal passiveThe patch must be approved by the platform.
CausativeWe are having the launch trailer made.
The fine distinction the test will hunt: the patch is being tested = in progress right now, look at the testers squinting; the patch has been tested = finished, the result is on the table. One is a process, the other is a report.

⚙️ Mini-table — the six errors of launch week

ErrorWrongRight
V2 for V3The build is builded nightlyThe build is built nightly
Missing beThe game released in MayThe game was released in May
Future passiveThe patch will approvedThe patch will be approved
Continuous passiveThe patch is testing nowThe patch is being tested now
Intransitive verbsThe launch was happenedThe launch happened
Causative orderI had tested the build by TomI had the build tested by Tom
🩹 One more classic: English is speak here → English is spoken here — and the passive question keeps its be: when released the trailer? → when was the trailer released?

Grammar → Speaking — the masterclass

15 mingoal: every tense, out loud, on demand
The 5-second rule: before every sentence ask silently: which tense is my be wearing? is tested, was tested, is being tested, has been tested, will be tested, must be tested — six costumes, one verb. The report dies if the be is missing.

🎙 Round 1 — RELEASE REPORT 2.5 minutes

The final task of the module: a 2.5-minute spoken release report about your (real or imaginary) launch. Every passive tense from the table must appear at least once: the build was compiled at dawn; the patch is being tested right now; forty thousand wishlists have been converted; the game will be released on Friday; the trailer must be approved first; we are having the party catered. The teacher ticks the tenses off a list as you speak.

… was compiled / released … … is being tested / localized … … have been sold / found … … will be released / must be approved … … are having … made / I had … tested…

🎙 Round 2 — Press Conference answer in passive

The teacher is a journalist and asks 6 sharp questions: How was it tested? When will it be released? Who was it designed by? What has been changed since the beta? Is localization being finished? What must be downloaded first? Every answer stays in the passive — the moment you say "we tested it", the journalist smells a story.

It was tested by… It will be released… … has been changed… It is being finished…

Homework

light — test week
🧑‍🏫 Teacher notes

Goal: consolidate Module 8 — the student operates the full passive system (present, past, continuous, perfect, future, modal) plus the causative, and measures the result honestly in Module Test 8 (5 + 5 written items and one recorded process description).

Suggested flow: Warm-up: the Marvel questions produce was-directed / was-made / would-be-cut — the module in one topic → Listening: the release report; second pass copies one is-being and one has-been sentence → Reading: the press release labels six tenses; the Marvel extension retells news in passives → Grammar: the student fills the seven-row system table from memory before looking; is being vs has been is the fine distinction → Speaking: Round 1 (RELEASE REPORT) is the exam performance — tick the tenses as she speaks; Round 2 forces passive answers under pressure; the Error hunt drill pre-briefs the test → Test: 10 written items + 1 recorded task → Homework: light by design.

Success criteria: Round 1 — all six passive tenses used at least once in 2.5 minutes, plus one causative; Test 8 — 70%+ written with both parts attempted; the system table — all seven rows filled with the student's own examples.

Error pocket (the six the test hunts): is builded · missing be (the game released) · will approved · is testing now · was happened · I had tested by Tom. Every slip found in Round 1 goes to the priority list with a promised fix.

Threads: the release report becomes Module 9's material (the report was said to be ready — reported speech); Lighthouse Point's reviews return in Module 10 (the game that changed everything — relative clauses); the cats' credits entry is now permanent lore.

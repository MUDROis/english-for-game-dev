Grammar — Third + Mixed Conditionals

10 minregrets + 4 exercises

THIRD CONDITIONAL — the time machine

  • Form: If + had V3, would have V3 — If we had tested earlier, we would have caught the crash.
  • Meaning: an unreal past — the thing did not happen, and you are describing its shadow.
  • Alternatives in the result: could have (ability), might have (possibility) — If we had shortened the demo, players might have finished the story.
  • The trap: would have is forbidden in the if-half. Ever. No exceptions.
Quick test: if the sentence contains a real date in the past that did not go the way you wanted — it is third conditional.

🔀 MIXED CONDITIONALS — two clocks in one sentence

  • Past cause → present result: If we had hired a second tester in autumn, we would be calmer now.
  • The if-half keeps had V3 (the past that did not happen), the result half takes would + infinitive (now).
  • Present cause → past result (rarer): If Tom were not so calm, he would have shouted during the launch.
  • Time words do the work: now, today in the result half is the mixed-conditional signal.
If the result half says now or this month — you are probably mixed, not third.

⚙️ Mini-table — which time machine is it?

SentenceWhy?
If we had tested the store page, we would have seen the bug.Both halves in the past — unreal past → third.
If we had hired a tester in autumn, we would be calmer now.Past cause, present result (now!) → mixed.
If we had a publisher, we would ship twice as fast.No had V3 — unreal present → second (Lesson 21).
If we would have tested earlier, we would have caught the crash.Wrong — would have must never enter the if-half.
If anyone breaks the build next month, they still bring cake.A standing law → zero. Some things survive every timeline.
🩹 Typical mistakes of Russian-speaking time travellers: If we would have tested earlier… → If we had tested earlier… (had V3 in the if-half) · If we had tested earlier, we would catch the crash → …we would have caught the crash (unreal past result needs would have V3 — unless you really mean now, then it is mixed on purpose) · If we had knew the risk… → If we had known the risk… (V3, not V2) · If I had more time last year… → If I had had more time last year… (had V3 needs the extra had).

Grammar → Speaking — the main section of the lesson

15 mingoal: regrets that sound professional
The 5-second rule: before every regret ask silently: did the result live in the past or now? If you catch yourself saying "if we would have tested" — stop, rebuild calmly: "if we had tested, we would have caught it." Had V3 + would have V3 — and never swap them.

🎙 Round 1 — Project Post-Mortem 5 regrets

Think of a real difficult case from your work or studies (a launch, a deadline, a group project) and describe it in 5 third conditional sentences. Model: if the demo had been shorter, players would not have skipped the story. No blaming — the grammar blames the timeline, not the people. 2 minutes.

If we had started earlier, we would have … If the demo had been shorter, players would not have … If someone had tested the page that morning, … If we had known the risk, we would have …

🎙 Round 2 — History Rewrite an alternative ending

Take any game or film with an ending you dislike and rewrite its history through had done / would have done: what would have happened if one key decision had been different? 90 seconds, at least four would-have sentences.

If the hero had saved the city in chapter one, … If the studio had kept the original ending, the game would have … If players had listened to the warning, …

🎙 Round 3 — Mixed Bag (the plan's core drill)

Four situations — two about the past, two about now. Choose the right form for each (third or mixed) and explain your choice in one clause: "…because the result is about today." This is the exact skill the module test will measure.

1 · You missed the wishlist deadline last spring. (past) 2 · Nobody taught you Git at university. You struggle now. (mixed) 3 · The demo crashed at gamescom last year. (past) 4 · You started English late. Your portfolio is thinner today. (mixed)

⚡ Speed Drill — a regret every 5 seconds

Open a card and instantly say the regret it hides — out loud, in the third (or mixed) conditional.

Homework

≤ 30 minutes in total
🧑‍🏫 Teacher notes

Goal: the student narrates unreal pasts — If + had V3, would have V3 — switches to mixed conditionals when the result is about now, and never lets would have into the if-half.

Suggested flow: Warm-up: painful launches and the decision they regret least — push answers to "if I had known…, I would have…" → Listening: the post-mortem; second pass copies two regrets word for word → Reading: the wiki page shows the complaint→time-machine rewrite; the Guardian extension rebuilds a real failure → Grammar: the mini-table's "which time machine?" rows are the heart; the video consolidates → Speaking: Round 3 (mixed bag) is the module's key drill — choose and justify → Writing: the rewritten post-mortem is the second portfolio artefact of the module.

Success criteria: Round 1 — 5 third conditionals, no would have in the if-half; Round 2 — four would-have sentences with a coherent alternative plot; Round 3 — all four situations classified correctly, with the reason said out loud.

Error pocket: would have in the if-clause · would + V2 (would catch for an unreal past result) · V2 after had (had knew) · missing second had (if I had more time last year) · overusing third where the student really means mixed — listen for now in the result half.
